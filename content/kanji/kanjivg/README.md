# KanjiVG Stroke Order Data

This directory contains KanjiVG SVG files for stroke order animations.

## Source
KanjiVG data is sourced from the KanjiVG project (https://kanjivg.tagaini.net/)
Licensed under Creative Commons Attribution-Share Alike 3.0.

## File Format
- Format: SVG
- Naming convention: `{unicode_codepoint}.svg` (e.g., `04e00.svg` for 一)
- Each SVG contains stroke path data with numbered stroke order

## Usage
These SVG files are used to render animated kanji stroke order in the learning interface.
The stroke paths can be animated sequentially to demonstrate proper writing order.
