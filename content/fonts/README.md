# Fonts Directory

This directory contains font files used by the Japanese Learning System.

## Required Fonts

### Noto Sans JP
- Source: Google Fonts (https://fonts.google.com/noto/specimen/Noto+Sans+JP)
- License: SIL Open Font License 1.1
- Weights needed: Regular (400), Medium (500), Bold (700)
- Files: `NotoSansJP-Regular.ttf`, `NotoSansJP-Medium.ttf`, `NotoSansJP-Bold.ttf`

## Installation
Download the font files from Google Fonts and place them in this directory.
Alternatively, the system can load fonts via CDN by referencing the Google Fonts URL
in the HTML head section.

## Usage
These fonts ensure proper rendering of Japanese characters (hiragana, katakana, kanji)
across all platforms and browsers.
