# Build Icons

Place your application icons here:

- `icon.ico` — Windows icon (256x256 recommended, .ico format)
- `icon.icns` — macOS icon (1024x1024, .icns format)
- `icon.png` — Linux icon (512x512 PNG)

These are used by electron-builder when packaging the application.

## Generating Icons

You can use tools like:
- [electron-icon-builder](https://www.npmjs.com/package/electron-icon-builder) to generate all formats from a single PNG
- [icoconvert.com](https://icoconvert.com/) for .ico conversion
- macOS built-in `iconutil` for .icns
